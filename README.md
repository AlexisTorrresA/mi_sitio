# Alexis Torres Labs

Sitio web personal bilingüe (ES/EN) de Alexis Torres Álvarez.

Incluye experiencia profesional, formación académica, docencia, conocimientos técnicos, proyectos, repositorios, certificaciones y enlaces profesionales.

Dominio objetivo: https://www.alexistorreslabs.com/

## Estructura

- `/` — versión en español
- `/en/` — English version
- `/assets/` — CSS y JavaScript
- `Dockerfile` + `nginx.conf` — despliegue contenedorizado
- `sitemap.xml`, `robots.txt`, `site.webmanifest` — SEO/PWA básico
